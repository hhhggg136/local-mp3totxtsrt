# 本地字幕工具

一个 macOS 原生小工具：音视频转中文、英语或西班牙语对白，导出带时间码的 TXT 和 SRT；把校对后的 SRT 导回来，积累按项目隔离的本地纠错词库。

当前源码与本机版本 **0.6.0**，新增可选本地说话人区分、A/B/C 改名和单句纠正。GitHub 已发布的独立安装包仍为 **0.5.0**；0.6.0 安装包尚未发布。

音频工作台：点击对白定位、单句试听、删除/恢复、裁剪和重排；保存轻量项目，导出音频与对应字幕。

## 直接下载安装

在 [Releases](https://github.com/hhhggg136/local-mp3totxtsrt/releases) 下载 `TingTingBeast-0.5.0-macOS26-AppleSilicon.dmg`，双击后把「本地字幕工具」拖入 Applications，再从应用程序打开。应用保留听听兽图标。

- 此安装包支持 **Apple 芯片 Mac、macOS 26 或更新版本**；未提供 Intel、Windows 或更早 macOS 的安装包。
- DMG 约 433 MiB，内含识别引擎、small 和 Silero VAD 模型，无需编译、开发环境或手动配置模型。建议预留至少 2 GB 空间，并按素材长度预留额外临时空间。
- **临时签名，未公证**：当前无 Apple Developer ID 证书，首次打开可能被系统阻止。确认项目下载来源后，如系统提供允许选项，可在「系统设置 → 隐私与安全性」允许打开。不需要关闭系统保护；如果无法正常允许，请停止并反馈。
- 首次翻译需要系统语言包，缺包时由系统提示下载。已在测试 Mac 实测六个互译方向、译文和双语两种模式；首次下载后自动继续、取消与重试通过。
- `SHA256SUMS.txt` 提供下载校验值；`verification.json` 是本次安装包的验证摘要。

本次实际挂载 DMG，把程序复制到项目之外，并通过沙箱禁止读取整个开发项目后识别约 84 秒的授权素材，生成 24 条字幕，原视频哈希不变。模型哈希、听听兽图标和嵌套签名检查通过。这验证了当前机器上离开源码目录后的识别流程，不等于其他 Mac 的系统兼容性或未公证程序首次启动验证。

Release 应用优先使用自身内部运行时，可独立移动和安装。下文要求保留 `.local` 相对位置的说明只针对源码构建版。源码 Git 仓库不含模型；Release 二进制安装包单独包含模型和引擎。个人音视频、字幕和学习记录不会打包。

维护者打包：先运行 `bash scripts/build.sh`，再运行 `python3 scripts/package-macos.py`。使用输出的 `package.json` 和授权测试媒体运行 `python3 scripts/verify-package.py /path/to/package.json /path/to/media.mp4` 验证独立运行。第三方许可位于应用包 `Contents/Resources/ThirdPartyLicenses`。

## 本地说话人区分（0.6.0）

工作台载入素材和对应 SRT 后，点击「说话人… → 本地分析说话人」。可以自动估计人数，或指定 1–8 人作为聚类约束；人数并非准确性保证。按原素材首次出现命名 A/B/C，不根据文字或句子顺序轮流贴标签。

- 同一窗口把 A 改成名字，更新所有关联对白；也可手动新增说话人。
- 单句纠正：选中对白，右侧「这句说话人」选择 A/B/C 或待确认。名字/归属与正文分开，支持撤销，随 `.tingting` 项目保存。
- 导出时选择「字幕和 TXT 包含说话人名字」；关闭则保留纯对白。时码、停顿、双语换行及剪辑映射保持原样。
- 读取旧项目；含说话人信息的项目升级为 schema 2，0.5.0 无法打开，避免旧程序静默丢掉名字。重新分析会提示替换已有分人结果并清空撤销历史，文字与剪辑不变；可先保存以保留 `.bak`。

使用约 28 MB 的 CAM++ 中英说话人嵌入模型和原生 sherpa-onnx/ONNX Runtime。每句最多读取 3 个、每个不超过 3 秒的窗口，模型在独立进程按需运行，结束/取消退出；临时音轨与嵌入清理，不建立跨视频声纹库。结果仅是候选，不推断真实身份。

**边界：按现有字幕逐句归属，不自动重切一句内不同人的文字，也不分离同时说话的声音。** 过短、过轻或窗口声音变化较大时保留待确认；相似声音、变声、游戏配音、BGM、压缩音质仍可能分错。首次真实游戏直播效果尚待用户录像验证。

实测：三位公开说话人的 6 段语音自动结果 A/B/A/C/C/B；约 60 分钟、678 句重复语音用于资源测试，完整窗口与分析子进程同时 RSS 合计峰值约 375 MiB，模型退出后窗口约 228 MiB（不含 Whisper 识别模型；不同于 physical footprint）。详见 [说话人验证记录](docs/speaker-diarization.md)。

源码配置先查看来源与位置，再明确下载：

```bash
python3 scripts/setup-speakers.py
python3 scripts/setup-speakers.py --download
bash scripts/build.sh
# 纯逻辑/音频编辑回归，不要求下载说话人模型
bash scripts/test.sh
# 本地真实模型流程，需已配置说话人模型
bash scripts/test-speakers.sh /path/to/authorized.wav /path/to/matching.srt
```

## 音频工作台（0.5.0）

在主窗口点击「打开音频工作台」。识别完成后会带入当前素材和字幕，也可独立导入音视频并载入对应 SRT。

- 点击对白文字或时间码定位，点耳机试听该句；连续播放可用空格暂停。
- 在「剪辑结果」中选择片段，使用上移/下移或拖动到另一片段前重排，删除可撤销或勾选「显示已删除」后恢复。
- 右侧输入原素材秒数微调片段边界，可修改对白文字。裁剪切入半句会提示核对文字，不自动猜测剩余内容。
- 「原始素材」为只读预览，保留原声音和时间码；「剪辑结果」显示重排后的波形、播放位置及字幕时间码。
- 保存为 `.tingting` 项目，仅保存路径、素材指纹和当前编辑状态；再次保存保留一个 `.bak`。最近 50 次撤销只在当前窗口有效。原素材移位后可重新定位，必须是同一份文件。
- 导出前明确选择原始/剪辑时间线，生成 M4A 或 WAV、对应 SRT/TXT 和映射核对说明；每次使用新文件夹，原素材不变。WAV 为 48 kHz、16 bit，保留单/双声道，多声道转换为双声道。

第一版为单素材、单音轨。视频只编辑音轨；波形是固定 2048 点的概览，支持点击定位。片段以对白分块（重叠对白保持同一块），相邻间隙默认中点分界，首尾及停顿声音保留。边界只能在各块初始范围内裁剪，暂不支持任意选区切割、缩放、多轨或视频导出。

音频引用原文件，播放缓冲目标 2 秒；重排不复制音频，也不启动识别模型。已用可区分的双声道声音验证试听顺序、M4A/WAV 声音顺序与 SRT 时间码一致；27 项编辑核心检查通过。5 分钟真实素材和 61 分钟合成素材完成连续 100 次重排及 WAV 导出：核心处理进程峰值 RSS 约 47 / 51 MiB（不含完整界面、不含识别模型）。完整界面的单独测量与可复现实验见 [工作台验证记录](docs/audio-workbench.md)。

## 使用

1. 打开 `本地字幕工具.app`，选择音视频及保存位置。
2. 输入项目名；只有同名项目的词库会用于本次识别。
3. 点击「开始识别」。输出文件夹包含 `字幕.srt`、`对白.txt`、`学习基准.srt`、`本次词库.json` 和诊断日志。
4. 保留 `学习基准.srt`，另存并校对 `字幕.srt`。
5. 打开「校对学习 / 词库」，选择学习基准及校对版，点击「学习本次修改」。以前生成的 SRT 也可以手动作为基准选择。
6. 逐条核对候选纠错，点击「确认使用」。下次识别将把该项目已确认的正确词作为 whisper.cpp 的初始提示；不做自动文本替换。

字幕时间码按**原素材的人声区间**生成：保留句间停顿，不把去掉停顿后拼接的识别音频时间码直接用于 SRT。一次只识别一个人声区间，导出边界不会包含识别时使用的额外声音上下文。详见 [时间码修复验证](docs/subtitle-timing-fix.md)。

候选词可以修改、停用、删除。修改正确词后需要重新确认。在主窗口关闭「使用已确认词库」可临时停用全部提示。

## “学习”的边界

这不是模型重新训练，也没有额外的大语言模型。程序比较校对前后的文字，提取有限长度的替换及相邻语境，保存在 SQLite 中。删除语气词、纯插入、纯删除、标点替换和长段润色不作为词语纠错。候选词不一定正确，必须核对。

只匹配**起止毫秒完全相同、且两份文件中均唯一**的字幕区间；移动时间码、合并或拆分的条目暂时跳过。重复导入完全相同的前后版本不会重复计数。导入提示会显示新增纠错和无法匹配的条目数。

根据少量关键词给出「AI 视频制作 / 电商 / 影视对白」场景建议。这只是分类提示，未识别的场景保持未知，不自动更换项目或混用词库。

词库可能改善专有名词，也可能引入错误。当前已验证提示流程可运行，**尚未用独立人工标注的新素材证明识别准确率提高**。时间码、断句、重叠对白仍需人工检查。

## 构建与首次配置

在 Apple silicon Mac 上验证；源码使用 Swift、SwiftUI、AppKit、AVFoundation、系统 SQLite 和 CryptoKit，无 Python 运行时依赖。当前构建和安装包以 macOS 26 为目标；实际验证环境为 macOS 26 和 Swift 6.3.3，其他版本尚未验证。

源码构建需要 Xcode Command Line Tools（Swift 和 C++ 编译器）、Git、CMake 和 curl。直接使用上方 Release 安装包无需这些开发工具。

```bash
# 只显示下载来源、体积和位置，不下载
bash scripts/setup-local.sh
# 明确下载模型并构建（首次需要网络，约 488.5 MB 模型）
bash scripts/setup-local.sh --download
# 已配置本地引擎及模型时，直接重新构建
bash scripts/build.sh
open 本地字幕工具.app
```

下载固定版本并校验 SHA-256；失败可以重新运行。现有模型校验失败时不会覆盖它。构建后的 app 默认从其所在项目目录查找 `.local` 引擎与模型，因此请保留 app 与项目目录的相对位置。首次配置后识别和学习均可离线运行。

## 本地数据与隐私

原始音视频只读，处理中间 WAV 位于独立临时目录，正常结束或失败后清理。输出位于用户指定的新文件夹，不覆盖已有字幕。

词库存放于 `~/Library/Application Support/LocalSubtitleTool/learning.sqlite`，仅包含项目名、短纠错词、次数、启用状态和防重复导入指纹，不包含音频或完整字幕。首次目录权限为 700，数据库为 600。识别输出会包含个人字幕与提示词，请自行保管；诊断日志可能包含本地路径。应用不上传素材或字幕，不发送遥测；首次系统翻译可能需要下载语言包。

Git 仓库不包含个人素材、字幕、输出报告、学习数据库、模型、引擎构建目录或生成的 app。上游 whisper.cpp 和模型的许可由其各自项目提供；本仓库的 MIT 许可只覆盖本项目代码。

## 内存与测试

每份导入 SRT 上限 5 MB、10000 条；每项目最多 5000 条候选，界面一次显示 200 条。SQLite 缓存目标 1 MiB，每次最多提供 32 个已确认词、总提示约 410 个字符。导入完成后释放对照数据，不加载音频或识别模型。

```bash
bash scripts/test.sh
bash scripts/check-memory.sh
# 可选：真实引擎停顿回归，需要 Python 3 和你授权测试的 16kHz 单声道 PCM16 WAV
# --clips 分别指定两段有对白的起止秒数；测试在中间插入 4 秒数字静音
python3 launcher/tests/timing_integration.py --app "$PWD/本地字幕工具.app" \
  --audio /path/to/speech.wav --clips 1:3 5:8
# 用 --lead-in 56 额外测试跨 60 秒处理窗口的停顿
```

详见 [内存验证](docs/learning-memory.md)。内存报告只覆盖本地纠错学习过程，不代表语音识别模型、所有系统缓存或整个图形界面的占用。

开发时可用 `LOCAL_SUBTITLE_ROOT` 指定引擎与模型的项目根目录，`LOCAL_SUBTITLE_DATA_DIR` 指定独立词库目录。测试使用独立临时词库，不修改日常学习记录。

## 识别语言（0.3.0）

主窗口「对白语言」可选中文、English、Español、自动检测。复用多语言 small 模型，无需额外模型，不翻译。自动模式逐个人声区间判断语言，短句可能误判，已知语言时建议手动选择。不同语言建议使用不同项目词库。

系统合成英语、西班牙语及西班牙语自动检测已完成识别验证；不代表真实口音或嘈杂环境下的准确率评估。

## 一键翻译与双语字幕（0.4.0）

需要 macOS 15 或更新版本，使用 Apple Translation 系统框架。识别完成后，在主窗口「翻译与双语字幕」选择原文和译文语言，点击「一键翻译」。支持中文、英语和西班牙语；使用自动识别时，请手动确认原文语言。也可通过「选择已有 SRT」翻译外部或已校对字幕。

- 额外生成 `译文.srt` 和 `译文.txt`。
- 勾选「双语字幕」（默认开启），同时生成 `双语字幕.srt` 和 `双语对白.txt`，原文在上、译文在下。
- 所有导出保留原 SRT 时间码和句间停顿。每次在原 SRT 旁创建独立 `翻译_目标语言_UUID` 文件夹，不修改原文、学习基准或词库。若该位置不可写，请先把 SRT 复制到可写文件夹。
- 翻译逐条进行，进度在窗口显示；失败或取消时不输出部分成品，可重试。译文需要人工核对，单句翻译缺少前后文，可能影响称谓、语气及专有名词。
- 首次使用由系统提示下载语言包，确认后才继续；下载完成后可在本地翻译。不需要云端 API Key，不把译文自动加入纠错学习库。

验证：原有词库及时间区间测试通过，新增导出检查覆盖多行 SRT、原译文顺序、保持时间码与停顿、拒绝空或缺失译文、原文不变和重复导出隔离。0.4.0 初次交付时语言包尚未安装，真实翻译未验证；0.4.2 已完成语言包下载和真实翻译验证，详见后文。

## 翻译完整验证与修复（0.4.2）

修复取消/重试、语言包后台下载后可能一直停留在准备阶段的问题。macOS 26 上对已安装语言包创建新的安装后会话；下载期间观察真实可用状态，完成后自动继续。提供「取消翻译」，以任务 ID 隔离旧请求，避免取消后的旧结果覆盖新任务。

2026-10-28，测试 Mac macOS 26.6.2：系统语言包下载完成；中文、英语、西班牙语六个互译方向，每方向测试译文和双语两种模式，共 12 个真实系统翻译导出用例，均生成文件。每个用例有三句合成测试文字，检查译文非空、输出语言、时间码与停顿保持、原文在上译文在下、原字幕哈希不变。另实测原生窗口的一键翻译、关闭双语、首次西班牙语下载后自动继续、取消 300 条字幕任务及取消后重试。

详细报告见 Release 的 `translation-verification.json`。测试证明这些样本的翻译/导出流程可用，不代表所有字幕、口语、专业词和长句的翻译质量；逐条翻译可能缺少上下文，成品仍需人工校对。

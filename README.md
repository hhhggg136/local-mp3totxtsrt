# 本地字幕工具

一个 macOS 原生小工具：音视频转中文对白，导出带时间码的 TXT 和 SRT；把校对后的 SRT 导回来，积累按项目隔离的本地纠错词库。

当前版本 **0.2.0**。已实现字幕生成和校对词库；音频剪辑、点击对白定位播放、波形和对白重排尚未实现。

## 使用

1. 打开 `本地字幕工具.app`，选择音视频及保存位置。
2. 输入项目名；只有同名项目的词库会用于本次识别。
3. 点击「开始识别」。输出文件夹包含 `字幕.srt`、`对白.txt`、`学习基准.srt`、`本次词库.json` 和诊断日志。
4. 保留 `学习基准.srt`，另存并校对 `字幕.srt`。
5. 打开「校对学习 / 词库」，选择学习基准及校对版，点击「学习本次修改」。以前生成的 SRT 也可以手动作为基准选择。
6. 逐条核对候选纠错，点击「确认使用」。下次识别将把该项目已确认的正确词作为 whisper.cpp 的初始提示；不做自动文本替换。

候选词可以修改、停用、删除。修改正确词后需要重新确认。在主窗口关闭「使用已确认词库」可临时停用全部提示。

## “学习”的边界

这不是模型重新训练，也没有额外的大语言模型。程序比较校对前后的文字，提取有限长度的替换及相邻语境，保存在 SQLite 中。删除语气词、纯插入、纯删除、标点替换和长段润色不作为词语纠错。候选词不一定正确，必须核对。

只匹配**起止毫秒完全相同、且两份文件中均唯一**的字幕区间；移动时间码、合并或拆分的条目暂时跳过。重复导入完全相同的前后版本不会重复计数。导入提示会显示新增纠错和无法匹配的条目数。

根据少量关键词给出「AI 视频制作 / 电商 / 影视对白」场景建议。这只是分类提示，未识别的场景保持未知，不自动更换项目或混用词库。

词库可能改善专有名词，也可能引入错误。当前已验证提示流程可运行，**尚未用独立人工标注的新素材证明识别准确率提高**。时间码、断句、重叠对白仍需人工检查。

## 构建与首次配置

在 Apple silicon Mac 上验证；源码使用 Swift、SwiftUI、AppKit、AVFoundation、系统 SQLite 和 CryptoKit，无 Python 运行时依赖。建议 macOS 14 或更新版本；实际验证环境为 macOS 26 和 Swift 6.3.3，其他版本尚未验证。

需要 Xcode Command Line Tools、Git、CMake 和 curl。程序及模型尚未制作成包含全部依赖的独立安装包。

```bash
# 只显示下载来源、体积和位置，不下载
bash scripts/setup-local.sh
# 明确下载模型并构建（首次需要网络，约 488.5 MB 模型）
bash scripts/setup-local.sh --download
# 已配置本地引擎及模型时，直接重新构建
bash scripts/build.sh
open 本地字幕工具.app
```

下载固定版本并校验 SHA-256；失败可以重新运行。现有模型校验失败时不会覆盖它。构建后的 app 默认从其所在项目目录查找 `.local` 引擎与模型，因此请保留 app 与项目目录的相对位置。首次配置后识别和学习均可离线运行。

## 本地数据与隐私

原始音视频只读，处理中间 WAV 位于独立临时目录，正常结束或失败后清理。输出位于用户指定的新文件夹，不覆盖已有字幕。

词库存放于 `~/Library/Application Support/LocalSubtitleTool/learning.sqlite`，仅包含项目名、短纠错词、次数、启用状态和防重复导入指纹，不包含音频或完整字幕。首次目录权限为 700，数据库为 600。识别输出会包含个人字幕与提示词，请自行保管；诊断日志可能包含本地路径。应用不发送网络请求或遥测。

Git 仓库不包含个人素材、字幕、输出报告、学习数据库、模型、引擎构建目录或生成的 app。上游 whisper.cpp 和模型的许可由其各自项目提供；本仓库的 MIT 许可只覆盖本项目代码。

## 内存与测试

每份导入 SRT 上限 5 MB、10000 条；每项目最多 5000 条候选，界面一次显示 200 条。SQLite 缓存目标 1 MiB，每次最多提供 32 个已确认词、总提示约 410 个字符。导入完成后释放对照数据，不加载音频或识别模型。

```bash
bash scripts/test.sh
bash scripts/check-memory.sh
```

详见 [内存验证](docs/learning-memory.md)。内存报告只覆盖本地纠错学习过程，不代表语音识别模型、所有系统缓存或整个图形界面的占用。

开发时可用 `LOCAL_SUBTITLE_ROOT` 指定引擎与模型的项目根目录，`LOCAL_SUBTITLE_DATA_DIR` 指定独立词库目录。测试使用独立临时词库，不修改日常学习记录。

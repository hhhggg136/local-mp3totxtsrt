# 听听兽 Windows 版（0.7.0 开发验证中）

本地音视频转 TXT/SRT、对白定位试听、片段删除与重排、项目保存、纠错词库、说话人候选分组与改名。
Windows 使用原生 Tk 桌面界面，无浏览器运行时，无常驻服务，不加入开机启动。

提供 x64（Windows 10 1903 或以上、Windows 11）和 ARM64（Windows 11）安装包。
程序安装到当前用户目录，不要求安装 Python。首次启动不自动下载模型。
识别和说话人模型随完整安装包提供；识别仅使用 CPU。

翻译使用 CTranslate2 + Argos 本地语言包。用户确认来源、大小和保存位置后才下载，
也可导入官方 .argosmodel。中西互译经英语中转。原文保留，额外生成译文 SRT/TXT 和双语 SRT。
ARM64 的翻译组件使用 Windows 的 x64 模拟，其余界面和识别组件原生运行。
字幕、音频、学习词库不上传。离线翻译效果与 macOS 的 Apple Translation 不相同，需要核对。

原始时间线保留素材时间；剪辑时间线按保留片段顺序播放和导出。
波形点击定位当前时间线，片段边界输入使用原素材秒数。
试听缓存使用磁盘 PCM，48kHz 双声道 16 位，约 659 MiB/小时；不会把整段音频放入内存。
关闭工具会清理本次缓存。异常退出后的旧 session 目录可能需要用户手动清理。
当前读取第一条音轨，支持不超过 24 小时的素材、10000 条对白。

项目与 Mac 使用同一 .tingting 格式；跨系统打开时重新定位同一份原素材，SHA-256 校验须通过。
关闭后不保存撤销历史，项目保存当前完整状态，重存保留上一版 .bak。
自动说话人分组不等于身份识别；短句、重叠、背景音乐和游戏音效可能导致待确认或错误，需试听纠正。

安装器不会删除 LocalSubtitleTool 用户数据。卸载后如需清除词库和语言包，可自行删除
%LOCALAPPDATA%\LocalSubtitleTool。导出的字幕、项目和原素材由用户保管。

Windows 首个预览版。安装器保留听听兽图标，双击安装到当前用户目录，不需要安装 Python，不加入开机启动。

- 普通 Intel/AMD 电脑下载 `Windows-x64-Setup.exe`；Windows 11 ARM 电脑或 Apple 芯片上的 Win11 ARM 虚拟机下载 `Windows-arm64-Setup.exe`。
- 本地中文/英语/西班牙语识别、TXT/SRT、原素材停顿时间码、可审核纠错词库。
- 对白点击定位、试听、边界调整、删除/恢复、重排、撤销/重做、项目保存、WAV/M4A 与字幕共用时间映射。
- 本地说话人候选分组、A/B/C 改名、单句人工纠正；重叠和游戏音效需要人工核对。
- 一键翻译额外生成译文 TXT/SRT 与双语 SRT，原文保留。首次语言包下载需确认，也可导入本地包；中文与西语之间经英语中转，译文需要核对。ARM 版翻译进程使用 Windows 的 x64 模拟。

完整安装包约 530 MiB，包含识别和说话人模型。大型模型在独立进程运行，完成后退出。
一小时试听 PCM 缓存约 659 MiB，使用磁盘缓存。项目和词库留在本地，不上传音频或字幕。

发布前自动验证包括真实识别、中文路径、6 个翻译方向、译文和双语时间码、安装后的界面创建、
实际 WAV/M4A 导出顺序、项目往返、原素材哈希与一小时音频准备内存检查。
具体机器与内存读数见 `Windows-verification.zip`，短样例读数不能当作所有长素材的上限。

预览版边界：用户虚拟机中的实际音频输出、手动点击完整流程以及 Windows 10 实机尚需验证。
当前主界面只提供音频工作台，暂不提供 macOS 的参考视频画面。跨系统项目打开时需要定位同一份原素材。
